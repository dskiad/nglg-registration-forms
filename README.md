## Privacy and security

This public repository contains **no submitted registrations or participant data**. Names, email addresses, phone numbers, travel details, response spreadsheets, and private configuration values must never be committed.

The example backend reads the target spreadsheet ID from Apps Script Properties instead of exposing it in source control.
